## 🍂 The Scenario

You've been asked to put together a short briefing for a **nature centre** that's planning its fall programs. Staff want to know:

> *When do Canada geese migrate in the fall, where do they go, which routes do they follow, and when is the best time to see them?*

Your first idea for a prompt is probably something like *"tell me about geese migration."* That will get you an answer, but not a great one. Your job is to use **Prompt Coach** to build a much better prompt, then run it in **Researcher** to get a detailed, well-sourced report.

---

## 🤖 Meet Your Agents

| Agent | What it does | When to use it |
|---|---|---|
| **Prompt Coach** | Helps you write, review and improve prompts. It asks questions, points out what's missing and rewrites your prompt. | **Before** you research, to turn a rough idea into a clear, detailed prompt |
| **Researcher** | Does deep, multi-step research. It searches many sources, reasons through the results and writes a structured report with citations. | **After** your prompt is ready, for questions that need more than a quick answer |

> 💡 **Tip:** Researcher takes longer than a regular Copilot chat, often several minutes. That's normal. It's reading and comparing many sources for you.

## 🧭 How to Use This Handout

1. Work through the steps **in order**. Each step builds on the one before.
2. Copy a prompt from a code block. Each code block has a copy button in GitHub.
3. Paste it into the agent named in that step and send it.
4. **Answer the agent's questions.** Both agents may ask you for more detail. That's how they help you.
5. **Review every result.** The agents are your assistants. You're still the researcher.

> ✏️ **Make it your own:** Once you've finished, try the same steps on a different animal, a different season or a different region.

## 🧠 Step 1: Plan Your Research

**Goal:** Know what you want *before* you ask.
**Where:** Your notepad (no agent yet)

Answer these four questions. They match the four parts of a strong prompt.

| Part | Ask yourself | Example answer |
|---|---|---|
| 🎯 **Goal** | What do I want to find out? | The fall migration path and timing of Canada geese |
| 🧩 **Context** | Who is it for, and why? | A nature centre planning fall programs |
| 📚 **Source** | Where should the information come from? | Trusted wildlife and government sources, such as bird conservation groups and wildlife agencies |
| 📋 **Expectations** | What should the answer look like? | A short report with headings, a timeline, a table of flyways and cited sources |

Now write your **first draft** prompt. Keep it simple. Prompt Coach will help you improve it.

```
Tell me about the fall migration of Canada geese.
```

> 🤔 **Think about it:** Is it "Canada geese" or "Canadian geese"? Check what Researcher calls them in its report. Small details like this matter in research.

---

## 🧑‍🏫 Step 2: Build the Prompt with Prompt Coach

**Goal:** Turn your rough draft into a strong, detailed prompt.
**Agent:** **Prompt Coach**

### 2.1 Get feedback on your draft

```
I want to use the Researcher agent to research the fall migration of Canada geese. Here is my draft prompt: "Tell me about the fall migration of Canada geese." What's missing, and how can I make it better?
```

```
Rate my prompt using Goal, Context, Source and Expectations. Tell me which parts are weak.
```

### 2.2 Add the details

```
Help me improve my prompt. The report is for a nature centre that is planning fall programs. I want to know when Canada geese start migrating, the main routes or flyways they use, where they spend the winter, and the best time to see them.
```

```
What questions should I answer so you can write a better research prompt for me? Ask me one question at a time.
```

```
Add guidance about sources. I want information from trusted sources, such as wildlife agencies, bird conservation organizations and university research, and I want every source cited.
```

### 2.3 Shape the output

```
Update the prompt so the report includes headings, a short summary at the top, a table of the main flyways, and a month-by-month timeline from August to December.
```

```
Add to the prompt that the report should explain how weather, food and daylight affect when geese migrate.
```

```
Add to the prompt that the report should mention resident geese that don't migrate, and explain how they differ from migratory geese.
```

### 2.4 Get the final version

```
Rewrite my prompt into one final version that's ready to paste into the Researcher agent.
```

```
Review the final prompt one more time. Is anything unclear or missing for a research agent?
```

> 📝 **Save it:** Copy the final prompt into your notepad. Compare it with your first draft from Step 1. What changed?

### 💡 Example: What a strong prompt can look like

Your prompt won't be exactly the same, and that's fine. Use this to compare.

```
Research the fall migration of Canada geese in North America. The findings are for a nature centre planning its fall public programs, so the language should be clear for a general audience.

Please cover:
1. When Canada geese begin and end their fall migration, and what triggers it (weather, food, daylight).
2. The main migration routes and flyways they use (Atlantic, Mississippi, Central and Pacific).
3. Where they spend the winter, and typical stopover areas along the way.
4. How migratory Canada geese differ from resident populations that don't migrate.
5. The best times and places to observe migrating geese in the fall.

Use trusted sources, such as government wildlife agencies, bird conservation organizations and university research. Cite every source.

Format the report with a short summary at the top, clear headings, a table of the four flyways (regions covered, timing, wintering areas), and a month-by-month timeline from August to December. Finish with 3 ideas for nature centre programs based on the findings.
```

## 🔎 Step 3: Run It in Researcher

**Goal:** Get a detailed, well-sourced report.
**Agent:** **Researcher**

1. Open **Researcher** and start a new chat.
2. **Paste your final prompt** from Step 2 and send it.
3. **Answer any clarifying questions.** Researcher often asks a few questions before it starts, for example about region or level of detail. Answer them clearly.
4. **Wait for the report.** You'll see Researcher's progress as it works.

> ⚠️ **Watch the clarifying questions.** If Researcher asks something your prompt should already have covered, go back to Prompt Coach and add it. That's a sign your prompt can be even stronger.

---

## 🧐 Step 4: Review and Follow Up

**Goal:** Check the report and dig deeper where you need to.
**Agent:** **Researcher** (same chat)

### 4.1 Check the sources

```
List every source you used, and tell me which organization published each one.
```

```
Which parts of this report are based on the strongest evidence, and which parts are less certain?
```

### 4.2 Go deeper

```
Focus on the Atlantic Flyway. Which states and provinces do the geese pass through, and when?
```

```
How has climate change affected the timing or routes of Canada goose migration?
```

```
Where in Ontario are the best places to see migrating Canada geese in October?
```

### 4.3 Make it easier to use

```
Turn the month-by-month timeline into a simple table.
```

```
Summarize this report in 5 bullet points for nature centre staff.
```

> 🤔 **Think about it:** Open two or three of the cited sources yourself. Do they really say what the report says? **Always** check before you share.

## 💡 Prompting Tips

| Tip | ❌ Instead of… | ✅ Try… |
|---|---|---|
| **State the goal** | "Tell me about geese" | "Research the fall migration path and timing of Canada geese" |
| **Give context** | No audience | "For a nature centre planning fall programs" |
| **Name your sources** | Any website | "Use wildlife agencies and bird conservation organizations, and cite them" |
| **Set expectations** | "Write something" | "Include a summary, headings, a flyway table and a timeline" |
| **Let the coach ask** | Guessing what's missing | "Ask me questions to improve my prompt" |
| **Follow up** | Starting over | "Now focus on the Atlantic Flyway" |

### 🧩 A simple prompt formula

```
[Goal] + [Context] + [Source] + [Expectations]
```

**Example:**

> *Research the fall migration routes of Canada geese* **(goal)** for a nature centre planning fall programs **(context)** using wildlife agencies and conservation organizations **(source)** with a flyway table and a month-by-month timeline **(expectations)**.
