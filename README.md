🧭 How to Use This Repository
Pick a topic. Open the folder for the skill you're working on, for example Data Analysis.
Read the handout. Each handout explains the scenario, the data and the order to work in.
Grab the practice file. Download the workbook and save your own copy to OneDrive or SharePoint, so Copilot can work with it.
Copy a prompt. Hover over any prompt and select the copy button in its top-right corner.
Paste it into Copilot, review the result and make it your own.
✏️ Make it yours: Once a prompt works, change one detail (a column, a name, a month) and try it again. That's how you build real prompting skills.

💡 Tips for Great Prompts
Tip	❌ Instead of…	✅ Try…
Be specific	"Look at this data"	"Show total Amount by Category, highest to lowest"
Give context	"Write a summary"	"Write a 3-bullet summary for my manager"
Ask one thing at a time	"Clean, chart and explain this"	One prompt per task
Follow up	Starting over	"Now break that down by month"
Check the result	Trusting it blindly	"Explain how you got that number"
🧩 A simple prompt formula
[Goal] + [Context] + [Source] + [Expectations]
Example:

Summarize the key trends (goal) in our FY26 travel spend for Finance (context) using the Expenses table (source) in 5 bullet points (expectations).

🧠 Remember: Copilot is your assistant. You're still the expert, so always review what it gives you.
